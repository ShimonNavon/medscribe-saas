How the Voice Agent & Kubernetes CI/CD Pipeline Work

DIAGRAM 01 · VOICE AGENT PIPELINE

From Microphone to Clinical Summary & PDF

Every node is linked directly to the Python & JS source files in ShimonNavon/meeting-recorder-.

  • • #1 AudioWorklet (16 kHz PCM) → WebSocket
  • • #2 Silero VAD splits speech on 700ms pauses
  • • #3 ElevenLabs Scribe v2 Realtime (~0.5s Hebrew+EN)
  • • #4 Spoken ID check-digit & name matcher (zero LLM PII)
  • • #5 GPT-5 Clinical Summary + Plain-Language Patient Letter

GitHub → Self-Hosted Runner → K8s → Synthetic Voice QA
